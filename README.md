# sql-operators-filtering-lab

## Overview
In this lab, I investigated login activity related to a security incident using SQL queries. The objective was to filter and analyze login attempts based on dates, times, and event IDs from the `log_in_attempts` table in the organization database.

This hands-on practice helped strengthen my understanding of SQL filtering techniques commonly used in cybersecurity and SOC analyst workflows.
